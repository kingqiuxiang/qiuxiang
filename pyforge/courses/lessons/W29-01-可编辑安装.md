# W29-01 可编辑安装

## 今晚能感觉到什么

包能被 import，版本非空。不要 conda。

## 和 Java 不同的一句

Java：`mvn install` 进本地仓库。  
Python：editable install 指向源码。

## 示范（先原样跑）

```powershell
uv run python -c "import pyforge; assert pyforge.__version__"
```

## 反例（必错）

```text
conda create -n pyforge——今晚禁止
```

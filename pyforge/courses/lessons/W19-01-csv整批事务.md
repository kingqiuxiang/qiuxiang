# W19-01 csv 整批事务

## 今晚能感觉到什么

三行合法 CSV 全进。第三行脏，零行进库。不用 pandas。

## 和 Java 不同的一句

Java：`OpenCSV` + 编程式事务。  
Python：`csv` 标准库 + 一个事务。

## 示范（先原样跑）

```powershell
uv run pytest tests/test_import_events.py -q
```

## 反例（必错）

```python
for row in rows:
    conn.commit()  # 一行一提交，脏行前面的留下了
```

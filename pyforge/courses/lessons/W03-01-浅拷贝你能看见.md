# W03-01 浅拷贝你能看见

## 今晚能感觉到什么

打印两行：浅拷贝后改内层，A 和 B **一起变**；深拷贝后改内层，A **不动**。不要背定义，看终端。

## 和 Java 不同的一句

Java：`new ArrayList<>(old)` 也是浅拷贝；`clone()` 更乱。要深拷贝得自己走或用序列化。  
Python：`b = a[:]`、`list(a)`、`copy.copy(a)` 都是浅的。`copy.deepcopy` 才深。没有「切片等于新集合且元素也是新的」。

## 示范（先原样跑）

`src/pyforge/copying.py`

```python
from __future__ import annotations

import copy


def shallow_rows(rows: list[list[str]]) -> list[list[str]]:
    return rows[:]


def deep_rows(rows: list[list[str]]) -> list[list[str]]:
    return copy.deepcopy(rows)
```

`tests/test_copying.py`

```python
from pyforge.copying import deep_rows, shallow_rows


def test_slice_is_shallow():
    a = [["gil"], ["uv"]]
    b = shallow_rows(a)
    b[0][0] = "changed"
    assert a[0][0] == "changed"


def test_deepcopy_isolates():
    a = [["gil"], ["uv"]]
    b = deep_rows(a)
    b[0][0] = "changed"
    assert a[0][0] == "gil"
```

用手摸：

```powershell
uv run python -c "from pyforge.copying import shallow_rows, deep_rows; a=[['gil']]; b=shallow_rows(a); b[0][0]='x'; print('shallow', a); a=[['gil']]; c=deep_rows(a); c[0][0]='x'; print('deep   ', a)"
```

要看到：

```text
shallow [['x']]
deep    [['gil']]
```

## 反例（必错）

```python
a = [["gil"]]
b = a  # 这连浅拷贝都不是，是两个名字绑同一对象
b.append(["new"])
print(a)  # a 也多了一行
```

`b = a` 是绑名字，不是拷贝。Java 里 `List b = a` 也一样，但 Python 人常以为切片是「值拷贝」。

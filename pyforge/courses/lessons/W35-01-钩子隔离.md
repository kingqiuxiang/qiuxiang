# W35-01 钩子隔离

## 今晚能感觉到什么

坏插件 `raise RuntimeError`，session 仍然存上。日志里有失败，主流程不回滚。

## 和 Java 不同的一句

Java：监听器异常常被框架吞或按配置走。  
Python：自己 `try/except` 包每个钩子，再 `raise GateFailed from err` 记下来但不阻断提交。



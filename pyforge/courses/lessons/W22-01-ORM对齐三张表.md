# W22-01 ORM 对齐 W17 字段

## 今晚能感觉到什么

`sessions` / `slices` / `gate_attempts` 三张模型能 `save`/`get`。迁移能 `migrate`。

## 和 Java 不同的一句

Java：JPA Entity 对齐 DDL。  
Django：`models.Model`。不要自定义 Manager 炫技。

## 示范（先原样跑）

```powershell
uv run python src/forge_web/manage.py test forge_web.tests.test_models
```

## 反例（必错）

```python
class SessionManager(models.Manager):
    pass  # 今晚禁止炫技
```

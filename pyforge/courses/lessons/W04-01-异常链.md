# W04-01 异常链：失败要带着原因

## 今晚能感觉到什么

`GateFailed` 的 `__cause__` 打出 `ZeroDivisionError`。不靠「堆栈有几层」——没有 `from` 时堆栈也是两层，那是 `__context__`，连接句不一样。

## 和 Java 不同的一句

Java：checked exception 逼你声明。  
Python：**没有 checked**。要链起来写 `raise GateFailed(...) from err`。光秃 `except:` 会吞一切，包括 `KeyboardInterrupt`。

## 示范（先原样跑）

`src/pyforge/gate.py`

```python
from __future__ import annotations

from dataclasses import dataclass


class GateFailed(Exception):
    pass


@dataclass(frozen=True)
class CapabilityGate:
    name: str

    def run(self, fn) -> None:
        try:
            fn()
        except Exception as err:
            raise GateFailed(self.name) from err
```

`tests/test_gate.py`

```python
from pyforge.gate import CapabilityGate, GateFailed
from pyforge.session import DailySession


def test_cause_is_kept():
    gate = CapabilityGate("w04")

    def boom() -> None:
        return 1 / 0

    try:
        gate.run(boom)
    except GateFailed as exc:
        assert exc.__cause__ is not None
        assert isinstance(exc.__cause__, ZeroDivisionError)
    else:
        raise AssertionError("expected GateFailed")


def test_session_stop_without_start_is_cause():
    gate = CapabilityGate("w04")
    try:
        gate.run(lambda: DailySession("W04").stop())
    except GateFailed as exc:
        assert isinstance(exc.__cause__, RuntimeError)
    else:
        raise AssertionError("expected GateFailed")
```

用手摸——只信 `__cause__`，不要数堆栈层数：

```powershell
uv run python -c "from pyforge.gate import CapabilityGate, GateFailed
try:
    CapabilityGate('w04').run(lambda: 1/0)
except GateFailed as e:
    print('cause', type(e.__cause__).__name__)"
```

要看到：`cause ZeroDivisionError`。

对比（不要写进 `gate.py`，只在脑子里跑）：

```python
# 没有 from：__cause__ 是 None；堆栈仍可能有两层（__context__）
try:
    1 / 0
except Exception:
    raise GateFailed("w04")
```

连接句：有 `from` 是 *The above exception was the direct cause*；没有是 *During handling of the above exception*。肉眼数层会看错。

## 反例（必错）

```python
try:
    1 / 0
except:  # 连 KeyboardInterrupt 都吞
    pass
```

光秃 `except:` 今晚出现在业务代码里 = 本课作废。

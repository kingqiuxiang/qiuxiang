# W28-01 本地 CI

## 今晚能感觉到什么

`pwsh -File scripts/ci.ps1`（或 `powershell`）跑 G1–G6 关键命令，全绿退出 0。不上云 CI 计费。

## 和 Java 不同的一句

Java：Maven `verify`。  
Python：一份本地脚本。Cloud Ubuntu 用 `pwsh`。

## 示范（先原样跑）

```powershell
pwsh -File scripts/ci.ps1
```

这是 **G7**。

## 反例（必错）

```text
脚本里 curl 收费云 CI——禁止
```

## 今晚只改这一刀

- `scripts/ci.ps1`

## 验收命令

```powershell
pwsh -File scripts/ci.ps1
```

## 下一课怎么接

脚本会跑了。下一课确认可编辑安装：`uv pip install -e .` 后能 `import pyforge`。

# W08-01 生成器与原子写

## 今晚能感觉到什么

`export_sessions` 写出 JSON 数组。中途失败时，目标文件要么是旧的完整文件，要么不存在，不会留下半截。

## 和 Java 不同的一句

Java：常先写临时文件再 `Files.move`。  
Python：生成器一次吐一条；落盘用 `tmp.replace(dest)`。不要 asyncio。

## 示范（先原样跑）

```powershell
uv run pytest tests/test_export.py -q
```

这是 **G2**：`test_cli` + `test_sqlite_repo` + `test_export` 必须一起绿。

## 反例（必错）

```python
dest.write_text("[")
for row in rows:
    dest.write_text(dest.read_text() + json.dumps(row))  # 半截文件
```

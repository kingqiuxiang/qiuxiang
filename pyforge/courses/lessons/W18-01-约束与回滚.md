# W18-01 约束与回滚

## 今晚能感觉到什么

同一 `(gate_name, slice_id)` 插两次，第二次失败，第一次也看不见“一半提交”。没有 Redis。

## 和 Java 不同的一句

Java：唯一索引 + 事务回滚。  
Python：sqlite `UNIQUE` + `with conn:`。冲突变异常，不要吞。

## 示范（先原样跑）

```powershell
uv run pytest tests/test_gate_attempts.py -q
```

## 反例（必错）

```python
except Exception:
    pass  # 约束失败被吞，门禁记录撒谎
```

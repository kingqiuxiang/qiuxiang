# W44-01 备份恢复

## 今晚能感觉到什么

`pyforge_backup` 写出文件；改库后再 restore，记录回到备份时。不上云盘 PKI。

## 和 Java 不同的一句

Java：DB dump。  
Django：自己导 JSON/sqlite 副本。

## 示范（先原样跑）

```powershell
uv run python src/forge_web/manage.py pyforge_backup
uv run python src/forge_web/manage.py test forge_web.tests.test_backup_restore
```

这是 **G11**。

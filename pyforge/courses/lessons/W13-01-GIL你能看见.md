# W13-01 GIL 你能看见

## 今晚能感觉到什么

两线程算同一段 CPU 循环，墙钟时间接近单线程，不是一半。数字印在测试里。

## 和 Java 不同的一句

Java：线程能并行吃多核（除非你自己加锁）。  
Python：CPython CPU 密集受 GIL。不要写 C 扩展。

## 示范（先原样跑）

```powershell
uv run pytest tests/test_gil_bench.py -q
```
